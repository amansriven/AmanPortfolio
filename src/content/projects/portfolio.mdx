## What it is

The site you're reading. I built it to be quick to load, easy to update, and simple to
copy. Every page is static except the contact form, and adding a project means adding
one file.

If you're a student who wants a portfolio of your own, you're welcome to start from
this one.

## Make it yours

1. **Fork and run it.** Fork [the repo](https://github.com/amansriven/AmanPortfolio),
   then run `npm install` and `npm run dev`.
2. **Swap in your details.** Your name, links, and roles live in `src/lib/site.ts` and
   `src/lib/experience.ts`. Colours, fonts, and spacing are all in
   `src/styles/tokens.css`.
3. **Add your projects.** Each one is an `.mdx` file in `src/content/projects/`, and the
   filename becomes the URL. The frontmatter is checked against a schema, so a missing
   field fails the build instead of quietly breaking a page.
4. **Deploy it.** Connect the repo to Cloudflare Workers, and every push to `main`
   goes live. Apart from a domain, it can run on free plans.
5. **Turn on the contact form (optional).** Add a Turnstile key and a Resend key as
   Worker secrets. The README lists each one.

<Callout label="Tip" title="Two things I learned after launch">
  Send contact-form email from your own domain rather than Resend's test address, or it will
  probably land in spam. And if you change your favicon, give Google a few weeks to pick it up;
  asking it to re-index your homepage in Search Console helps.
</Callout>
